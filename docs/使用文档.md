## 1. 产品简介

**易道命理**是一个融合多种传统术数与现代占卜方式的 Web 平台，包含：

- **用户端**：国风界面，支持建档、测算、查看报告
- **管理后台**：模块开关、AI 配置、数据统计
- **确定性引擎**：八字、黄历、姓名等由代码计算，结果稳定可复现
- **AI 层（预留）**：可在后台配置多模型，按模块开启 AI 白话解读

### 核心使用逻辑

```
建档（一次） → 命理档案 → 选择术数模块 → 查看测算报告
```

无需档案的模块（如测字、黄历、塔罗）可直接访问对应页面测算。

## 3. 普通用户使用指南

### 3.1 首次使用：创建命理档案

1. 打开首页，点击 **「开始测算」** 或顶部 **「建档」**
2. 填写以下信息：

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 姓名 | 否 | 可选填 |
| 性别 | 是 | 男 / 女 / 未知 |
| 历法 | 是 | 公历 或 农历 |
| 出生年/月/日 | 是 | 数字输入 |
| 出生时辰 | 否 | 0–23，留空表示未知 |

3. 提交后进入 **命理档案页**（URL 形如 `/profile/xxxxxxxx`）

> 建议保存档案页链接，后续测算会自动携带 `profileId` 参数。

### 3.2 从档案页开始测算

档案页展示：

- 公历 / 农历日期
- 生肖、星座、纳音
- 四柱八字摘要
- 全部可用术数入口

点击任意模块卡片即可进入对应测算页。

### 3.3 无需档案的模块

以下模块可直接从首页或导航进入，无需建档：

- 黄历择日、测字、姓名测算、周易、六爻、梅花、小六壬、灵签、解梦、塔罗、奇门、大六壬、太乙、杯筊、面相、手相、MBTI 配对、四柱反查

### 3.4 查看测算结果

每个模块页操作流程：

1. 填写该模块所需参数（如有）
2. 点击 **「开始测算」**
3. 页面下方显示 **结构化报告**（规则模板生成）
4. 若管理员已开启 AI，还会显示 **AI 解读** 区块

### 3.5 合婚配对特殊说明

合婚需要 **两份档案**（均为当前登录账号下的档案）：

1. 在「我的档案」至少创建两份档案（如「本人」「伴侣」）
2. 将其中一份设为当前档案（作为本人）
3. 进入 **合婚配对** `/match`
4. 在下拉列表中选择对方档案（无需手填 UUID）

### 3.6 测算历史

每次测算结果会自动存档。可在：

- 顶栏「历史」、档案页入口，或直接访问 `/reports`
- 测算完成后的「查看历史详情」链接

点击某条记录可复看完整模板报告与（若有）AI 解读。  
若管理员已为账号开启「人生洞察」，报告页可额外积分解锁**流年事件倾向、六亲时间线、行业方向**（文化娱乐参考，非事实预言）。

## 6. AI 解读配置

### 6.1 推荐配置流程

1. 登录管理后台
2. **AI 模型配置** → 添加供应商（填 Base URL、Key、模型名；Key 会加密存储）
3. **AI 开关** → 开启「全局 AI」
4. **AI 开关** → 为需要的模块单独开启（如八字、测字；面相/手相还需识图模型）
5. 用户端重新测算，报告将出现 AI 解读区块

### 6.2 联调验收清单

- [ ] 已添加至少一个 `isActive` 供应商，列表显示「已加密」
- [ ] 全局 AI = 开，目标模块 AI = 开
- [ ] 普通模块（如八字）测算后出现「AI 解读」
- [ ] 故意填错 Key：测算仍返回模板报告，不整页报错（失败回退）
- [ ] 面相/手相：上传清晰照片可出结果；未开 AI 时页面提示需配置识图模型
- [ ] 关闭全局 AI 后，新测算不再出现 AI 区块

### 6.3 兼容的 API 格式

平台使用 OpenAI 兼容的 `/chat/completions` 接口，以下服务均可接入：

- OpenAI
- DeepSeek
- 通义千问（OpenAI 兼容模式）
- 智谱 GLM
- Moonshot（Kimi）
- 其他自建 OpenAI 兼容网关

识图（面相/手相）需选用支持 vision / `image_url` 的模型。  
若使用火山 **Agent Plan**（`api/plan/v3`），请用 `doubao-seed-2.0-lite` / `mini` / `pro`；**不要**配置 `doubao-1.5-vision-pro`（该型号仅按量推理可用，Plan 会返回 UnsupportedModel）。

### 6.4 默认行为与积分计费

- 配置 `VOLC_ARK_API_KEY` 后，`npm run db:seed` 会自动写入「火山方舟 Token Plan」供应商并开启全局 AI
- **积分制**（详见 Agent Hub [`billing-requirements.md`](file:///E:/agent-hub/projects/suanming/docs/billing-requirements.md)）：
  - 新用户注册默认赠送 **10** 积分
  - 默认扣费：普通测算 **1** · AI 解读 **10** · 面相手相视觉 **20** · **人生洞察解锁 30**
  - 充值汇率：**1 元 = 10 积分**（微信/支付宝后续对接；后台可赠送）
  - 收费总开关与档位：管理后台「计费设置」
  - 用户启停、赠分、**是否允许人生洞察**：管理后台「用户管理」
  - 人生洞察（流年倾向 + 六亲时间线）：须管理员开权限 → 报告页再扣积分解锁；八字/大运最完整，面相手相可生成主题倾向，绑定出生档案更准
  - 积分不足无法测算；游客可浏览模块但不可测算
  - 前台 `role=admin` 测算不扣积分
  - 登录 / 注册 / 后台登录按 IP 限流（超限 HTTP 429）；测算接口另有限流
- API Key 使用 AES-256-GCM 加密；派生密钥来自 `AI_KEY_SECRET` 或 `JWT_SECRET`
- Anthropic 兼容备用地址（工具侧）：`VOLC_ARK_ANTHROPIC_BASE_URL=https://ark.cn-beijing.volces.com/api/plan`

火山环境变量：

| 变量 | 说明 |
|------|------|
| `VOLC_ARK_API_KEY` | Token Plan API Key |
| `VOLC_ARK_BASE_URL` | 默认 `https://ark.cn-beijing.volces.com/api/plan/v3` |
| `VOLC_ARK_MODEL` | 默认文本模型，如 `doubao-seed-2.0-mini` |
| `VOLC_ARK_VISION_MODEL` | 识图模型：Agent Plan 下用 `doubao-seed-2.0-lite`（或 mini/pro）。**不要**用 `doubao-1.5-vision-pro`（仅按量 api/v3，Plan 会报 UnsupportedModel） |
| `AI_USER_QUOTA` | 已废弃（改用积分），保留兼容 |

## 8. 内容与规则自定义

### 8.1 修改签文、生肖文案等

1. 编辑 `content/` 下对应 JSON 文件
2. 重启服务（`npm run dev` 或 `npm run start`）
3. 用户重新测算即可看到新内容

### 8.2 扩展姓名笔画字库

编辑 `content/name-strokes.json`，按 `"字": 笔画数` 格式添加汉字。

### 8.3 扩展面相/手相词条

编辑 `content/face-rules.json` 或 `content/palm-rules.json`：

```json
{
  "features": [
    {
      "feature": "你的特征名",
      "meaning": "解读文案",
      "category": "分类"
    }
  ]
}
```

### 8.4 新增模块（开发者）

1. 在 `lib/hub/module-registry.ts` 注册模块
2. 在 `lib/engine/` 实现计算引擎
3. 在 `lib/hub/divination-router.ts` 添加路由分支
4. 在 `lib/report/template-renderer.ts` 添加报告模板
5. 创建 `app/(site)/{module}/page.tsx` 页面
6. 执行 `npm run db:seed` 同步数据库

## 10. 常见问题

### Q1：提示「请先从档案页进入」？

部分模块需要 `profileId` 参数。请先 `/onboarding` 建档，从档案页点击模块入口。

### Q2：模块显示「该模块已关闭」？

管理员在后台禁用了该模块。登录 `/admin/modules` 重新启用。

### Q3：出生时辰不知道怎么办？

建档时时辰可留空。八字仍可按年月日排盘，时柱显示「未知」，结果中会标注精度降低。

### Q4：为什么没有看到 AI 解读？

默认 AI 关闭。需在管理后台开启全局 AI + 模块 AI，并配置有效的模型供应商。

### Q5：数据库在哪里？

默认路径：`E:\suanming\data\suanming.db`（SQLite 文件）。

### Q6：如何重置数据库？

```bash
# 删除数据库文件后重新 seed
rm -rf data/suanming.db
npm run db:seed
```

### Q7：测算结果和别的网站不一样？

不同系统采用的历法边界、姓名笔画标准、紫微/奇门算法可能不同。本平台采用固定规则，详见各模块精度说明。

### Q8：如何跑测试验证引擎？

```bash
npm test
```
