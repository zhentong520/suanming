# 生产部署检查清单

上线前逐项确认。完整步骤与 Nginx/PM2/Docker 说明见 **[部署方案.md](./部署方案.md)**。

## 入口

- [ ] 前台可访问（本地默认 http://localhost:9111）
- [ ] 管理后台可登录：**http://localhost:9111/admin/login**（或 `https://域名/admin/login`）
- [ ] 已修改默认管理员密码（勿长期使用 `admin123`）

## 环境与密钥

- [ ] `.env.local` / 生产环境变量已配置，且**未**提交到 Git
- [ ] `JWT_SECRET` 为足够长的随机串（非 `change-me-in-production` / `dev-secret`，建议 ≥16 位）
- [ ] 管理员密码已在后台「系统设置」改为非默认值（勿依赖 `admin123`）
- [ ] 生产建议设置 `STRICT_PROD_SECRETS=true`（弱密钥时拒绝启动）
- [ ] 生产环境下用户登录 Cookie 带 `Secure`（`NODE_ENV=production` 或 `AUTH_COOKIE_SECURE=true`）
- [ ] 可选：设置独立 `AI_KEY_SECRET`（与 JWT 分离）
- [ ] `NEXT_PUBLIC_SITE_URL` 为正式 HTTPS 域名
- [ ] `NEXT_PUBLIC_SITE_NAME` / 描述文案符合上线品牌

## 数据与进程

- [ ] `npm run db:seed` 已在目标环境执行
- [ ] SQLite 数据目录可写，并纳入备份（默认 `data/suanming.db`）
- [ ] `npm run build` 成功
- [ ] `npm run start`（或进程管理器）监听约定端口（默认 9111）
- [ ] 反向代理已配置 HTTPS 与 WebSocket（若需要）

## 功能冒烟

- [ ] `npm test` 通过
- [ ] `npm run smoke`（需先启动服务）注册 → 建档 → 八字 → 管理登录成功
- [ ] 合婚可从档案下拉选择对方
- [ ] `/reports` 可看到测算历史；档案页「操作记录」可点进对应报告（新测算起带 reportId）
- [ ] 前台顶栏可见 AI 剩余次数（管理员显示「AI 无限」）
- [ ] 管理后台仪表盘：今日测算跨日清零、近 14 日趋势有数据
- [ ] （可选）`npm run mcp` 可在 Cursor 调 `run_divination`（见 docs/mcp.md）
- [ ] （可选）微信开发者工具打开 `miniprogram/` 能登录并测算（见 docs/miniprogram.md）
- [ ] 若启用 AI：按使用文档 §6.2 验收
- [ ] 若启用微信分享：按使用文档 §6.5 验收；须配置真实 `WECHAT_APP_ID` / `SECRET` 与 JS 安全域名

## 安全

- [ ] 管理后台不可被搜索引擎随意索引（或限制访问）
- [ ] AI Provider 列表中 Key 显示为已加密，接口响应不含明文 Key
- [ ] 免声明页脚可见
